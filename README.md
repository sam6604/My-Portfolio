# Sai Samanvith S — Portfolio

Personal portfolio site, built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Editing content

All resume content (projects, experience, skills, certifications, education, contact links) lives in one place: [`lib/data.ts`](./lib/data.ts). Edit that file to update the site — no need to touch the components.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint

## Deploying

The site is a standard Next.js app, so it deploys with zero config on [Vercel](https://vercel.com): import this GitHub repo and it builds automatically on every push to `main`.
